Release Notes
  1. Windows 10/11 first-time setup: Install Arduino’s official Nano ESP32 USB driver before continuing. Download the official Arduino ESP32 package, extract it, open the drivers folder, then run dpinst-amd64.exe on 64-bit Windows 10 or any Windows 11 PC. Use dpinst-x86.exe only for 32-bit Windows 10. This is only required once.
  2. Connect your Nano ESP32 via USB directly to your PC or Mac (not through a USB hub) and double click the Nano's RST button to enter recovery mode (a GREEN LED will strobe when successful).
  3. Click “Connect and Flash” and select “Nano ESP32 (bootloader)”. When “Authorize USB JTAG” appears, follow the instruction shown below the button.
  4. After installation, continue with the “Setup” steps listed on GitHub.
