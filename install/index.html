Release Notes
  1. Connect your Nano ESP32 via USB directly to your PC or Mac (not through a USB hub) and double click the Nano's RST button to enter recovery mode (a GREEN LED will strobe when successful).
  2. Click “Connect and Flash” and select “Nano ESP32 (bootloader)”. If this browser profile has not authorized USB JTAG before, click “Authorize USB JTAG” first, then Press RST on the Nano once while the chooser is open and select the USB JTAG device when it appears. If USB JTAG is already authorized, simply press RST when prompted. If the process does not continue, press RST once again until it does.
  3. After installation, continue with the “Setup” steps listed on GitHub.
